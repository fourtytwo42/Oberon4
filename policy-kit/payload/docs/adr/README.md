# Architecture Decision Records (ADRs)

Use ADRs for architecture-impacting changes.

## Naming
- `NNNN-short-title.md` (for example: `0001-service-boundary.md`)

## Minimum Content
- Context
- Decision
- Consequences
- Alternatives considered
- Links to issue(s)

## Local Gate
`pre-push` requires an ADR update when architecture-impact paths change.
