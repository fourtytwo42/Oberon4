# Memory Map

Canonical artifact locations for session recovery and handoffs:

- `docs/context-pack.md` - active context snapshot
- `docs/debug-brief.md` - active debugging state
- `docs/plans/` - plans
- `docs/change-requests/` - change requests
- `docs/handoffs/` - handoff/checkpoint artifacts
- `docs/adr/` - architecture decisions
- `docs/security/` - security checklist artifacts
- `docs/maintainability/` - maintainability checklist artifacts
- `docs/runbooks/` - runbooks

Naming guidance:
- prefer `<type>-<topic>.md`
- avoid ad-hoc artifact placement outside canonical directories
