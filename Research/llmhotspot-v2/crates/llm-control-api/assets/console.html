# LLM Hotspot Agent Playbook

This guide is for agents automating this console backend.

## Base URLs
- Local API base: `/v1` on local endpoint shown in UI.
- Remote API base: `/v1` on remote endpoint shown in UI.
- Remote console page may include `admin_key` in the URL for admin actions.

## Auth Requirements
- Read-only calls usually work with API key bearer auth.
- Admin/management calls require console admin session or `admin_key`.
- For remote console operations, prefer the remote console URL with `admin_key`.

## Core Discovery Calls
- `GET /v1/version` -> build and git hash.
- `GET /v1/endpoints` -> local/remote endpoint URLs.
- `GET /v1/models` -> advertised model IDs.
- `GET /v1/auth/status` -> entitlement and capability state.
- `GET /v1/diagnostics` -> request/failover/error telemetry.

## Chat Interfaces (Universal Routing)
- OpenAI-compatible: `POST /v1/chat/completions`
- Anthropic-compatible: `POST /v1/messages`
- Google-compatible: `POST /v1/google/models/{model}:generateContent`

Route by model prefix:
- `gpt*` -> OpenAI provider
- `claude*` -> Anthropic provider
- `gemini*` -> Google provider

## OAuth Account Management
- List accounts: `GET /v1/oauth/accounts`
- Reorder account priority: `POST /v1/oauth/accounts/{account_id}/priority`
- Enable account: `POST /v1/oauth/accounts/{account_id}/enable`
- Disable account: `POST /v1/oauth/accounts/{account_id}/disable`
- Disconnect account: `POST /v1/oauth/accounts/{account_id}/disconnect`

Provider-specific usage:
- OpenAI usage: `GET /v1/oauth/accounts/{account_id}/wham-usage`
- Anthropic usage: `GET /v1/oauth/anthropic/usage/{account_id}`
- Google usage: `GET /v1/oauth/google/usage/{account_id}`

Google model verification:
- Verify usable models: `GET /v1/oauth/google/models/verify/{account_id}`
- Force refresh verify: `GET /v1/oauth/google/models/verify/{account_id}?refresh=1`

## API Key Management
- List keys: `GET /v1/keys`
- Create key: `POST /v1/keys`
- Toggle key: `POST /v1/keys/{key_id}/enable` or `/disable`
- Delete key: `POST /v1/keys/{key_id}/revoke`
- Copy raw key once: `GET /v1/keys/{key_id}/copy` (admin context)

## Usage Counter Controls
- Reset one model: `POST /v1/usage/reset-model/{model}`
- Reset one OAuth account: `POST /v1/usage/reset-oauth/{account_id}`
- Reset one API key: `POST /v1/usage/reset-key/{key_id}`
- Reset all usage: `POST /v1/usage/reset-all`

## Diagnostics and Debugging
- Main diagnostics: `GET /v1/diagnostics`
- Wire capture (if enabled): `GET /v1/diagnostics/wire`
- Clear wire capture: `POST /v1/diagnostics/wire/clear`

## Safe Operating Rules for Agents
- Do not delete/revoke accounts or keys unless explicitly asked.
- Do not silently substitute a different model family.
- Prefer disabling over deleting when asked to "turn off" access.
- Confirm final state with `GET` after every mutating `POST`.
